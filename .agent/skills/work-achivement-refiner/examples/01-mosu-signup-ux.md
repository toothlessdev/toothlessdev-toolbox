# Example 1: MOSU – 신청 플로우 UX 개선

## Input

메인 페이지 할인 혜택 배너 제안 및 도입을 통해 신청페이지 진입률 12% 개선

BACKGROUND
모의수능 신청·결제 플랫폼에서 신청 단계는 결제로 이어지는 핵심 전환 구간이었습니다.
하지만 신청 페이지로의 진입이 기대보다 낮아, 전체 신청 건수가 목표에 미치지 못하는 문제가 있었습니다.

PROBLEM
Google Analytics 분석 결과, 메인 신청페이지 진입률이 낮아 신청 건수가 기대 대비 저조
가격 및 할인 혜택에 대한 정보를 메인페이지에서 인식하지 못해 발생하는 문제로 가정

ACTION
얼리버드 할인 혜택을 페이지 상단에서 즉시 인지할 수 있는 배너 UI 제안
React.createPortal 을 사용해 Stacking Context 에 영향받지 않도록 구현

RESULT
메인페이지 → 신청페이지로의 진입률 12% 개선
동일 기간 기준 신청 건수 약 30% 증가 (1주 기준 46회 신청 → 63회 신청)
초기 가격 정보 노출이 신청 단계 유입 및 실제 신청 수 증가로 이어짐을 검증

---

## Structured Output

# 메인 배너 구조 개선을 통한 신청페이지 진입률 12% 향상

## BACKGROUND

모의수능 신청·결제 플랫폼에서 신청 단계는 결제로 이어지는 핵심 전환 구간이었습니다.  
신청 페이지 진입률이 기대 대비 낮아 전체 신청 건수가 목표에 미치지 못하는 상황이었습니다.

## PROBLEM

Google Analytics 분석 결과, 메인 신청페이지 진입률이 낮았습니다.  
가격 및 할인 혜택 정보를 메인에서 인지하지 못하는 것이 원인으로 가정되었습니다.

## ACTION

얼리버드 할인 혜택을 상단에 즉시 인지 가능한 배너 형태로 제안 및 구현했습니다.  
React.createPortal을 사용해 Stacking Context의 영향을 받지 않도록 구성했습니다.

## RESULT

메인 → 신청페이지 진입률 12% 개선  
동일 기간 신청 건수 약 30% 증가 (46회 → 63회)  
가격 정보 노출이 실제 신청 증가로 이어짐을 검증

### Tech Keywords

React.createPortal, Google Analytics, UX Optimization, Conversion Funnel
